# Zotero → GitHub

Адаптация скрипта из проекта `vkr-ai-mission`. Выгружается только корневая коллекция **«Гедеон — Русская Америка»** и её потомки, включая записи, находящиеся только в дочерних коллекциях.

## Команда (PowerShell, локально)

```powershell
$env:ZOTERO_API_KEY = '<ключ из вашего защищённого хранилища>'
.\scripts\export-zotero-research.ps1
Remove-Item Env:ZOTERO_API_KEY
```

Не вставляйте ключ в чат и не сохраняйте его в репозитории. Проверка ключа выполняется через `/keys/current`, вручную вводить Zotero User ID не нужно.

Результат: `research/zotero/catalog.json`. Его **не надо коммитить автоматически**, пока не проверены публичность всех названий, тегов и метаданных. Заметки, сканы и вложения из API-экспорта исключены.

Это одностороннее чтение Zotero → файл; изменений в Zotero скрипт не делает. Проверка соединения и наличие коллекции пока не выполнялись.
