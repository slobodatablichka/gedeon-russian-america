# Правила помощника

1. Гедеон — главный герой; исторические экскурсы функциональны.
2. Не выдумывать цитаты, страницы, библиографию, факты и локаторы.
3. Разделять первичные свидетельства, научные выводы, гипотезы и художественные образы.
4. Записки Гедеона: отдельно хранить оригинал, буквальную транскрипцию, сравнение вариантов и комментарий. Пропуск сам по себе не доказывает цензуру.
5. Не публиковать сканы и закрытые заметки без проверки прав и отдельного согласования.
6. Перед работой читать документы по порядку в START.md и проверять HEAD GitHub.
7. Zotero — исходная библиотека. **Первым делом использовать проверенный локальный путь Zotero Desktop + `curl.exe` + `scripts/check-zotero-local.ps1` без API-ключа**; инструкция `research/zotero/README.md`. Коллекция `YWQFHUER`, учитываются вложенные коллекции. Web API с ключом — только резерв при установленной необходимости. Публичный экспорт GitHub содержит только проверенные библиографические метаданные; секреты не коммитить. Не утверждать, что помощник видит локальный JSON, пока он реально не передан. При ошибке — диагностировать по этапу, не менять несколько компонентов сразу.
8. Существенные архитектурные изменения, публикацию статьи, push/merge согласовывать. На текущее поручение распространяется согласие на начальную настройку репозитория.
9. Писать небольшими завершёнными шагами, без преждевременного создания большого текста.

## Маршрут исходных документов
По умолчанию использовать Яндекс Диск → локальный скрипт → GitHub → анализ → ссылки в Zotero. При рабочем маршруте не просить пользователя вручную прикреплять файлы к чату. Большие сканы оставлять на Яндекс Диске и извлекать необходимые фрагменты.

## Смысловая рамка (утверждена 2026-10-26)
**Мотив статьи** — размышление о неисповедимости путей Господних, открывающейся в судьбе человека, призванного к необыкновенному служению. Иеромонах Гедеон (Гавриил Федотов), воспитанник и преподаватель Белгородской духовной семинарии, прошёл путь от духовной школы до далёких берегов Русской Америки, где ему довелось стать участником истории православной миссии.

**Цель статьи** — проследить этот путь на основании исторических свидетельств, прежде всего записок самого Гедеона, показать его служение в обстоятельствах эпохи и через два столетия обратиться к вопросу: не находит ли дело, которому он посвятил свою жизнь, своеобразного продолжения в миссионерском призвании современной Белгородской православной духовной семинарии?

Это авторское христианское размышление о Промысле, призвании и продолжении служения Церкви через поколения, **а не доказательство известных нам намерений Промысла Божия или документально установленной прямой преемственности** между деятельностью Гедеона и современной БПДС. Не превращать статью в заранее заданное прославление Гедеона. Исторические утверждения проверять по источникам.

Гедеон — основной герой, но не предмет предварительного прославления. Белгородская духовная школа прошлого и современная БПДС могут стать композиционным обрамлением. «Юнона и Авось» — самостоятельное позднейшее художественное отражение эпохи, не историческое свидетельство. Исследовательские вопросы и тезисы выводить из авторского замысла и каркаса статьи, не собирать факты ради накопления.

## Утверждённый стиль
Сохранять научно-публицистическое сочетание **строгой исторической достоверности и живого повествования**. Умеренная романтика допустима при описании экспедиции, Русской Америки, человеческих судеб и переходов, если опирается на реальные обстоятельства. Не придумывать мысли, чувства, диалоги, детали пейзажа или причинные связи; художественное и документальное различать. См. `governance/WRITING-GUIDE.md`.
