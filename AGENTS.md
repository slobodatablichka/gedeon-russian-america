# Правила помощника

1. Гедеон — главный герой; исторические экскурсы функциональны.
2. Не выдумывать цитаты, страницы, библиографию, факты и локаторы.
3. Разделять первичные свидетельства, научные выводы, гипотезы и художественные образы.
4. Записки Гедеона: отдельно хранить оригинал, буквальную транскрипцию, сравнение вариантов и комментарий. Пропуск сам по себе не доказывает цензуру.
5. Не публиковать сканы и закрытые заметки без проверки прав и отдельного согласования.
6. Перед работой читать документы по порядку в START.md и проверять HEAD GitHub.
7. Zotero — исходная библиотека. Публичный экспорт GitHub содержит только проверенные библиографические метаданные; секреты не коммитить.
8. Существенные архитектурные изменения, публикацию статьи, push/merge согласовывать. На текущее поручение распространяется согласие на начальную настройку репозитория.
9. Писать небольшими завершёнными шагами, без преждевременного создания большого текста.
