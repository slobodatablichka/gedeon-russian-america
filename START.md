# Гедеон — Русская Америка

Исследовательский проект научно-публицистической статьи об иеромонахе Гедеоне (Гаврииле Федотове).

## Первый шаг в сеансе
Прочитать `START.md`, `AGENTS.md`, `governance/PROJECT-INSTRUCTIONS.md`, `governance/CURRENT-STATE.md`; проверить актуальный GitHub HEAD и необходимый каталог Zotero. Не заменять файловое состояние памятью чата.

## Разделение ролей
- GitHub: исследовательский план, карточки свидетельств, транскрипции, разночтения, авторский текст и журнал решений.
- Zotero: библиографический первоисточник, идентификаторы, локаторы, PDF и заметки.
- Отдельное хранилище: большие мастер-сканы и иные оригинальные бинарные файлы.

## Каркас статьи
0 — Беринг; 1 — РАК и начало миссии; 2 — миссия до Гедеона; 3 — биография Гедеона; 4 — записки Гедеона; 5 — Резанов и «Юнона и Авось». Введение, заключение и детализация согласуются отдельно.

## Цикл работы
Инвентаризация → поиск → записи Zotero → свидетельства со страницами и Zotero Key → тезисы → утверждение → текст → фактчекинг.

## Zotero API
См. `research/zotero/README.md` и `scripts/export-zotero-research.ps1`. Файл `research/zotero/catalog.json` создаётся только после реального запроса к Zotero API. Синхронизация не подтверждена, пока запрос не выполнен.

## Постоянный маршрут документов
По умолчанию: публичная папка Яндекс Диска → выборочная загрузка скриптом на Windows (прямой Wi-Fi, минуя Happ) → небольшие файлы в GitHub → чтение/анализ помощником → результаты в GitHub и ссылки в Zotero. Сканы больших размеров остаются на Яндекс Диске; при необходимости забираем только страницы. Не просить ручной перенос в чат, если этот маршрут доступен. Скрипт для записок: `scripts/fetch-gedeon-docx.ps1`.

## Утверждённые мотив и цель статьи (2026-10-26)
**Мотив статьи** — размышление о неисповедимости путей Господних, открывающейся в судьбе человека, призванного к необыкновенному служению. Иеромонах Гедеон (Гавриил Федотов), воспитанник и преподаватель Белгородской духовной семинарии, прошёл путь от духовной школы до далёких берегов Русской Америки, где ему довелось стать участником истории православной миссии.

**Цель статьи** — проследить этот путь на основании исторических свидетельств, прежде всего записок самого Гедеона, показать его служение в обстоятельствах эпохи и через два столетия обратиться к вопросу: не находит ли дело, которому он посвятил свою жизнь, своеобразного продолжения в миссионерском призвании современной Белгородской православной духовной семинарии?

Это авторское христианское размышление о Промысле, призвании и продолжении служения Церкви через поколения, **а не доказательство известных нам намерений Промысла Божия или документально установленной прямой преемственности** между деятельностью Гедеона и современной БПДС. Не превращать статью в заранее заданное прославление Гедеона. Исторические утверждения проверять по источникам.

Дополнительный культурный мотив: история Н. П. Резанова и позднейшее художественное воплощение в «Юноне и Авось»; историческое лицо и художественный образ строго различать. Утверждённый каркас разделов 0–5 сохраняется. Конкретную композицию введения и заключения согласовать при подготовке тезисно-исследовательской карты.
