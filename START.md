# Гедеон — Русская Америка

Исследовательский проект научно-публицистической статьи об иеромонахе Гедеоне (Гаврииле Федотове).

## Первый шаг в сеансе
Прочитать `START.md`, `AGENTS.md`, `governance/PROJECT-INSTRUCTIONS.md`, `governance/CURRENT-STATE.md`; проверить актуальный GitHub HEAD и необходимый каталог Zotero. Не заменять файловое состояние памятью чата.

## Разделение ролей
- GitHub: исследовательский план, карточки свидетельств, транскрипции, разночтения, авторский текст и журнал решений.
- Zotero: библиографический первоисточник, идентификаторы, локаторы, PDF и заметки.
- Отдельное хранилище: большие мастер-сканы и иные оригинальные бинарные файлы.

## Каркас статьи
0 — Беринг; 1 — РАК и начало миссии; 2 — миссия до Гедеона; 3 — биография Гедеона; 4 — записки Гедеона; 5 — Резанов и «Юнона и Авось». Введение, заключение и детализация согласуются отдельно.

## Цикл работы
Инвентаризация → поиск → записи Zotero → свидетельства со страницами и Zotero Key → тезисы → утверждение → текст → фактчекинг.

## Zotero API
См. `research/zotero/README.md` и `scripts/export-zotero-research.ps1`. Файл `research/zotero/catalog.json` создаётся только после реального запроса к Zotero API. Синхронизация не подтверждена, пока запрос не выполнен.

## Постоянный маршрут документов
По умолчанию: публичная папка Яндекс Диска → выборочная загрузка скриптом на Windows (прямой Wi-Fi, минуя Happ) → небольшие файлы в GitHub → чтение/анализ помощником → результаты в GitHub и ссылки в Zotero. Сканы больших размеров остаются на Яндекс Диске; при необходимости забираем только страницы. Не просить ручной перенос в чат, если этот маршрут доступен. Скрипт для записок: `scripts/fetch-gedeon-docx.ps1`.
